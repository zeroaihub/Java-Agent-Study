## ① 为什么学

- 把前七章零散知识整合成一个完整、可运行、带人设、自动选工具、有兜底的 Agent 作品。

## ② 是什么

- 能力边界：查天气/时间/计算；超范围礼貌拒绝；异常友好提示。
- 内部流转：ask() → system(人设+规则) + user + tools(三工具) + call() → Agent Loop → 综合回答。
- system prompt = Agent 岗位说明书（人设/规则/输出风格），把通用 LLM 约束成业务 Agent。

## ③ 怎么用

- Java 完整代码：ChatClient + SYSTEM_PROMPT + tools + try-catch 兜底。
- Python 简版：create_tool_calling_agent + AgentExecutor（承担 Agent Loop）。
- 验证：/day3/assistant 单意图/多意图/超范围三种情况。

## ④ 用在哪

- 通用骨架 = system prompt + 工具集 + 自动 Loop + 异常兜底。
- 换工具即换产品：客服/办公助手/知识库/量化助手。

## ⑤ 避坑与优化 + 代码点评

- V1 做得好：人设、三工具自动选、统一入口兜底、日志、结构化 JSON。
- V1→V2 优化：多轮记忆(ChatMemory)、工具治理(Registry/权限)、可观测(traceId/监控)、Loop 上限、超时熔断、安全、流式。
- 常见错误：忘兜底、system prompt 太弱、无能力边界、无记忆做多轮。
