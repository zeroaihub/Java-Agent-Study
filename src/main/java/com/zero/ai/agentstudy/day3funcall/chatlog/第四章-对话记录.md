## ① 为什么学

- 手写三阶段协议约 80 行；Spring AI 一行 `.tools(...).call().content()` 搞定。

## ② 是什么

- 四概念：@Tool / @ToolParam / ChatClient / ChatModel。
- 注册与调用流程：反射扫描 @Tool → 转 tools 数组 → LLM 返回 tool_calls → 反射执行 → 回传 → 循环到 stop。

## ③ 怎么用

- 4 步：定义工具 → 构建 ChatClient 挂工具 → 暴露 Controller → 配置模型。
- 验证：控制台出现 `[WeatherTool] 被调用` 即链路跑通。
- Python 对照：bind_tools + AgentExecutor/LangGraph 自己写循环。

## ④ 用在哪

- Java 团队做 Agent 首选；把现有 @Service 包一层 @Tool 即可复用业务逻辑。

## ⑤ 避坑与优化

- 常见错误：工具类没 @Component、方法非 public、description 语言不匹配、模型不支持 FC、base-url 配错。
- 优化：返回精简 JSON、超时降级、低 temperature、日志埋点、动态挂载工具。
