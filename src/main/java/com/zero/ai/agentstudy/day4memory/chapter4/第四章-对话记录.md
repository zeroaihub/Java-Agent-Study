## ① 为什么学（核心价值）

- 长期 Memory 决定 Agent 是否能持续理解用户。
- 企业级 Agent 不能把聊天流水直接当用户画像，必须区分稳定信息、近期信息和敏感信息。
- UserProfile 是长期个性化的核心模型。

## ② 是什么（概念与原理）

长期 Memory 适合保存：

- 姓名、职业、技能、兴趣、学习目标、偏好、最近项目。

不适合保存：

- 密码、token、身份证、银行卡、验证码等敏感信息。
- 一次性闲聊、未经确认的推测、容易伤害用户权益的标签。

## ④ 用在哪（应用场景）

- AI 学习助手：长期记住用户职业、目标、偏好。
- AI 客服：长期记住用户等级和服务偏好。
- AI 办公助手：长期记住写作风格和常用格式。

## ⑤ 避坑与优化（进阶提升）

- 长期画像必须支持用户查看、修改、删除。
- 敏感信息默认拒绝入库。
- 最近项目需要更新时间或过期策略。
- 画像更新建议记录来源、置信度和审计日志。
