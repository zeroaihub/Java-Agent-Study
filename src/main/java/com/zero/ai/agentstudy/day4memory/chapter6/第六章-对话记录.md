# 第六章 对话记录：Java 实现 Memory Agent

> 归档时间：Day4 学习 · 第六章
> 教学框架：五段式（为什么学 / 是什么 / 怎么用 / 用在哪 / 避坑与优化）

---

## ① 为什么学（核心价值）

- 本章把 Memory 理论落到工程实现。
- 目标是实现最近 10 轮聊天、Session 隔离、Redis 缓存边界、MySQL 用户画像边界、自动更新用户兴趣。

## ② 是什么（概念与原理）

架构：

```text
Controller
   |
   v
MemoryAgentService
   |
   +--> ChatMemoryStore(Redis-like)
   +--> UserProfileRepository(MySQL-like)
   +--> ProfileSignalExtractor
   +--> Prompt Builder
```

## ④ 用在哪（应用场景）

- AI 学习助手：记住职业、目标、偏好。
- AI 客服：记住当前会话和长期用户等级。
- AI 办公助手：记住最近任务上下文和写作偏好。

## ⑤ 避坑与优化（进阶提升）

- Redis 需要 TTL 和 LTRIM。
- MySQL 画像更新要去重、记录更新时间。
- 自动抽取兴趣不能直接覆盖用户显式信息。
- 并发更新需要乐观锁或 merge 策略。
