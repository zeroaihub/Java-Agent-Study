## ① 为什么学（核心价值）

- 企业级 Memory 难点在治理：成本、生命周期、画像更新、隐私、RAG 协同。
- Demo 能跑不代表能上线，Memory 必须有策略和边界。

## ② 是什么（概念与原理）

企业级 Memory 治理：

```text
压缩策略
生命周期
用户画像更新策略
Memory + RAG + Tool 协同
```

## ④ 用在哪（应用场景）

- AI 知识库：Memory 识别用户，RAG 提供制度事实。
- AI 客服：Memory 记录用户偏好，Tool 查询实时订单。
- AI 量化交易：Memory 记录风险偏好，RAG 检索研报和策略文档。

## ⑤ 避坑与优化（进阶提升）

- Memory 与 RAG 冲突时必须有事实优先级。
- 用户画像必须可查看、可修改、可删除。
- 压缩摘要要保留关键事实和时间范围。
- 敏感数据禁止进入普通 Memory。
