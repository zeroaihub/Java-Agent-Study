## ① 为什么学（核心价值）

- 最终目标是完成一个能记住姓名、职业、学习目标，并根据长期记忆调整回答的 Agent。
- 这是商业化 Agent 的基础形态。

## ② 是什么（概念与原理）

```text

   |
   v
FinalMemoryAgentService
   |
   +--> FinalChatMemoryStore
   +--> FinalProfileRepository
   +--> FinalProfileExtractor
   +--> PromptBuilder
```

## ④ 用在哪（应用场景）

- AI 学习助手：个性化教学路径。
- AI 客服：长期客户偏好。
- AI 办公助手：写作风格和项目背景。
- AI 量化交易 Agent：风险偏好和策略关注点。

## ⑤ 避坑与优化（进阶提升）

- 当前实现是教学版内存存储，生产环境应替换 Redis 和 MySQL。
- 自动画像抽取应升级为 LLM 结构化抽取 + 置信度 + 用户确认。
- 后续接入 RAG 时，PromptBuilder 需要增加 `ragContext` 分区。
- 需要补充跨 session 隔离、画像更新、敏感信息拒绝保存的测试。
